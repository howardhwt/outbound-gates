# Approved capability list

A draft may only describe what is on this list. The list is for the fictional product, Acme Transcribe. Replace it with your own, and keep a source next to each line.

## Not cleared for a cold email

- Accuracy against any named competitor. No benchmark has been run.
- Speed or capacity figures. None has been measured.
- Language coverage. The list changes too often to quote.
- How easy it is to switch. Integration effort depends on the reader's stack.

## Keeping it honest

- The numbers on this list also go in `own_facts` in the gate config, so the checker accepts them without a claim row.
- When a capability changes, change it here first. A draft that quotes last month's list passes the gate and is still wrong, so date the list when you edit it.
- If a prospect asks about something in the second section, answer it on the thread with what you know. The restriction applies to unprompted claims.
